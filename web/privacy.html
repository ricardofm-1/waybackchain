Privacy

Wayback Wallet has no accounts and stores no addresses on its servers.

Cookies

  • hl_addr keeps your address list on this device so you don't retype it. It's set when a lookup succeeds and lasts 180 days. Use “Clear saved addresses” to delete it.
  • hl_sid is a random ID that counts your daily lookups (10 per day). Page scripts can't read it. It lasts 365 days.

Both cookies are needed for features you ask for, so there is no consent banner.

What we send and log

Your addresses leave your browser only inside a lookup request. Our server forwards them to public blockchain data providers to fetch balances, and does not log them. Server logs record only the chain, whether the request succeeded, and how long it took.
