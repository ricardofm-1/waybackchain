Privacy

Wayback Chain has no accounts, no analytics and no advertising. It looks up public blockchain data for the addresses you enter and shows what they held on a date you choose.

Cookies

Both cookies serve features you ask for, so there is no consent banner.

CookieWhat it holdsWhyLasts
hl_addr Your address list, on this device only. So you don't retype it. Saved after a successful lookup. “Clear saved addresses” deletes it. 180 days
hl_sid A random ID with a signature. Page scripts can't read it. Counts your lookups (10 per day). 365 days

Where your addresses go

Addresses leave your browser only inside a lookup request to our server, which forwards each one to the public data provider for its chain:

  • Bitcoin: mempool.space, with blockstream.info as a fallback
  • Ethereum: Alchemy
  • Solana: Helius, with the public Solana RPC as a fallback
  • XRP Ledger: s2.ripple.com, with xrplcluster.com as a fallback
  • Cardano: Blockfrost

Each provider has its own privacy policy. For USD values we ask DefiLlama for token prices; that request names coins and token contracts, not your addresses.

What our server keeps

  • Logs: the endpoint, whether it succeeded and how long it took. Never addresses, never IP addresses.
  • Daily counters: one per visitor ID and one per IP address. The IP is stored only as a keyed hash, and each counter holds just today's count.
  • Result cache: results for dates at least two days old are kept for 30 days so repeat lookups are fast. Each entry is filed under a keyed hash of the chain, address and date, and the stored result has the address removed, so the cache can't be searched for an address.
  • Price cache: historical prices per date. These contain no personal data.

Captcha

Lookups are protected by Cloudflare Turnstile, which runs a privacy-preserving check in your browser. See Cloudflare's privacy policy.

Your choices

Delete both cookies in your browser at any time; the site works without saved addresses, and a new visitor ID is issued when needed. Nothing else we hold is linked to you.
